# 口粮与饲料粮占比 · 三法平均（2024–2035）

9.30 进展汇报前端页：对最近三次预测（MLP、逻辑斯谛 S 曲线、二次多项式）按年等权平均后的口粮/饲料粮占比可视化。

- 口径：FAO 中国大陆 Domestic supply（口粮=Food，饲料粮=Feed）
- 样本期：2000–2023；预测期：2024–2035
- 页面入口：`index.html`
- 数据：`average.csv` / `average.json`

## 本地预览

直接用浏览器打开 `index.html`，或：

```bash
python3 -m http.server 8080
```
